---------For web page start up-----------

To run the web page that uses vite:
    in /app dir: npm start


---------For python FastAPI server start up-----------

Windows: 
    in /app dir: .venv\Scripts\activate
    pip install -r requirements.txt
    and then: python -u -m uvicorn backend.main:app                #--reload

Debian:
    in /app dir: source .venvlinux/bin/activate 
    pip install -r requirements.txt
    and then: python -u -m uvicorn backend.main:app                #--reload


---------For redis server start up (for the saved queries)-----------
Debian:
    (if not installed) sudo apt install redis-server
    redis-server
